# Ciências Radiológicas

Portal de notícias e plataforma de estudos focada na disseminação de conhecimento científico sobre diagnóstico por imagem, tomografia computacional, ressonância magnética, ultrassonografia e medicina nuclear.

---

## Sobre o Projeto

O projeto foi desenvolvido para oferecer uma interface moderna no formato de portal noticioso, integrando um blog com artigos técnicos e uma seção dedicada à análise e resolução de casos clínicos práticos.

---

## Tecnologias Utilizadas

* Next.js (App Router)
* React
* TypeScript
* Tailwind CSS v4
* Lucide React (Ícones)

---

## Estrutura do Projeto

* src/app: Estrutura de rotas do Next.js, incluindo o layout global e a página principal.
* src/components: Componentes reutilizáveis como Header, Footer e cards de casos clínicos.
* src/types: Definições de interfaces do TypeScript.
